# Source reconciliation

The public tree combines the surviving original-bot and research lineage with the final retired V2 implementation.

## V2 release baseline

Before public sanitization, 68 source and package files in the saved retirement archive matched the October 15 checkout byte for byte. The only differing archived file was the strategy configuration. This edition uses the saved deployed configuration.

The archive does not include the entire test and tooling tree. Those files come from the matching October lineage. Their presence is not proof that each tool was deployed. Historical rollout documents retain their own activation caveats.

## Publication changes

The original `bot` directory became `v1`. Relative paths were updated. Owner addresses and known own-transaction references in test material were replaced consistently, including ABI-encoded addresses. Those samples retain their test purpose but are no longer original receipt exports.

A research performance workload lacked the later required maximum-tax field. The public fixture now states its 200-bps upper screen boundary explicitly. A short-experiment test import was updated for the moved tree. No live trading process was changed.

Personal infrastructure defaults were replaced with local examples. The V2 environment example starts in shadow mode. No credentials or runtime databases are included.

The original full Git history, dirty worktrees, ignored data, and unmodified captures were preserved privately before cleanup. Public history starts at this sanitized edition.
